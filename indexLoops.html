Part 1: For Loops

Use a for loop when you know exactly how many times to repeat something.

What is a For Loop?

A for loop repeats a block of code a specific number of times. Think of it like counting laps around a track — you know you want to run exactly 5 laps.

💡

Real-world example: A microwave beeps 3 times when done. The microwave uses a "repeat 3 times" instruction — just like a for loop!

For Loop Structure

// Structure: for (start; condition; update) for (int i = 1; i <= 5; i++) { // code that repeats }
  1. Initialization: int i = 1 — Create a counter variable and set its starting value.
  2. Condition: i <= 5 — Keep looping as long as this is true.
  3. Update: i++ — After each loop, change the counter (i++ means add 1).

🔢 Count from 1 to 5

Print the numbers 1 through 5, one per line.

public class CountUp { public static void main(String[] args) { for (int i = 1; i <= 5; i++) { System.out.println("Number: " + i); } } }
// Output: Number: 1 Number: 2 Number: 3 Number: 4 Number: 5

The loop starts at i=1 and runs until i is greater than 5. Each time it prints the current value of i, then adds 1.

✖️ Multiplication Table (×3)

Print the 3 times table from 3×1 to 3×5.

public class TimesTable { public static void main(String[] args) { for (int i = 1; i <= 5; i++) { int answer = 3 * i; System.out.println("3 x " + i + " = " + answer); } } }
// Output: 3 x 1 = 3 3 x 2 = 6 3 x 3 = 9 3 x 4 = 12 3 x 5 = 15

⭐ Star Rating Bar

Print a "star bar" showing 4 stars (like a rating system).

public class StarBar { public static void main(String[] args) { System.out.print("Rating: "); for (int i = 1; i <= 4; i++) { System.out.print("★ "); } System.out.println(); System.out.println("4 out of 5 stars!"); } }
// Output: Rating: ★ ★ ★ ★ 4 out of 5 stars!

Part 2: While Loops

Use a while loop when you don't know in advance how many times to repeat — just keep going while a condition is true.

What is a While Loop?

A while loop keeps repeating as long as a condition remains true. It checks the condition before each iteration.

💡

Real-world example: You keep eating pizza slices while you're still hungry. You don't know how many slices you'll eat in advance — you just keep going until the condition (hungry) becomes false!

While Loop Structure

int counter = 1; // Initialize BEFORE the loop while (counter <= 5) { // Condition checked each time System.out.println(counter); counter++; // Update INSIDE the loop! }
⚠️

Important! Always update your variable inside a while loop. If you forget, the condition never becomes false and the loop runs forever — this is called an infinite loop.

🚀 Countdown to Launch

Count down from 5 to 1, then print "Blast off!"

int count = 5; while (count >= 1) { System.out.println(count + "..."); count--; } System.out.println("Blast off! 🚀");
// Output: 5... 4... 3... 2... 1... Blast off! 🚀

💰 Savings Goal

Keep adding $10 to savings until you reach $50.

int savings = 0; while (savings < 50) { savings += 10; System.out.println("Savings: $" + savings); } System.out.println("Goal reached!");
// Output: Savings: $10 Savings: $20 Savings: $30 Savings: $40 Savings: $50 Goal reached!

🎮 Game Lives

A player starts with 3 lives and loses one each round until they have 0.

int lives = 3; while (lives > 0) { System.out.println("Playing... Lives left: " + lives); lives--; } System.out.println("Game Over!");
// Output: Playing... Lives left: 3 Playing... Lives left: 2 Playing... Lives left: 1 Game Over!

Part 3: Do-While Loops

A do-while loop always runs at least once — it checks the condition after running the code block.

What is a Do-While Loop?

A do-while loop is like a while loop, except the code runs first, and then the condition is checked. This guarantees the loop body runs at least one time.

💡

Real-world example: At a restaurant, you always get the menu at least once — then you decide if you want to order more. You do the action first, then check whether to repeat.

Do-While Structure

int i = 1; do { System.out.println(i); // Runs FIRST i++; } while (i <= 3); // Condition checked AFTER
⚠️

Don't forget the semicolon! The do-while loop ends with } while (condition); — that semicolon at the end is required.

For vs. While vs. Do-While — At a Glance

// FOR — use when you know the count for (int i = 1; i <= 5; i++) { ... } // WHILE — use when you don't know the count; checks first while (condition) { ... } // DO-WHILE — always runs at least once; checks after do { ... } while (condition);

🍽️ Restaurant Menu

Show the menu at least once, then ask if they want to see it again (simulated).

int viewCount = 0; do { viewCount++; System.out.println("Showing menu... (view #" + viewCount + ")"); } while (viewCount < 2); System.out.println("Thank you! Enjoy your meal.");
// Output: Showing menu... (view #1) Showing menu... (view #2) Thank you! Enjoy your meal.

🎲 Dice Roll

Roll a die (simulated), always roll at least once.

int roll = 0; int rollCount = 0; do { roll = (rollCount + 1) * 3 % 6 + 1; // simulated rollCount++; System.out.println("Roll #" + rollCount + ": You got " + roll); } while (roll != 6); System.out.println("Rolled a 6! Stop.");
// Sample output: Roll #1: You got 4 Roll #2: You got 1 Roll #3: You got 6 Rolled a 6! Stop.

🌡️ Temperature Alert

Read temperature at least once and keep reading while it's above 100°F.

int temp = 105; // simulated readings int reading = 0; do { reading++; System.out.println("Reading #" + reading + ": " + temp + "°F"); temp -= 3; } while (temp > 100); System.out.println("Temperature safe!");
// Output: Reading #1: 105°F Reading #2: 102°F Temperature safe!
